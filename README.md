# my-website

A simple portfolio website for Akpu Roseline.

## Project structure

- `index.html` — main landing page
- `assets/css/styles.css` — stylesheet
- `assets/js/scripts.js` — site behavior and interactions
- `assets/img/` — image assets

## Usage

Open `index.html` in your browser to view the site.

For development, keep the file paths as shown above and update the asset files under `assets/`.
